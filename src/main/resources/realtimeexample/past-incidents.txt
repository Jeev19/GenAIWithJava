ID: INC-3877
SERVICE: cart-service
SYMPTOMS: heap grew steadily for two hours after a release, pods OOMKilled one by one, cache hit rate near zero
ROOT CAUSE: new SessionKey class used as a HashMap key had no equals() and hashCode(), so every lookup missed and the cache grew without bound
FIX: rolled back, added equals() and hashCode() to the key (a Java record), replaced the HashMap with a size-bounded Caffeine cache
